# Consolidated context guidance

Read this when agent context, repository instructions, or durable documentation are being reorganized.

- Put stable rules in durable entrypoint documents and transient work in plans or handoffs.
- Load the narrowest relevant source instead of broad context dumps.
- Remove duplication and state which document wins when sources conflict.
- Keep navigation shallow and make conditional references explicit.
- Verify that a fresh session can find the authoritative source without hidden knowledge.
