# Consolidated interaction and personality guidance

Read this when a design needs motion or personality beyond the core visual system.

- Add motion only when it communicates cause, hierarchy, or progress.
- Respect reduced-motion settings and keep interactions interruptible.
- Use delight sparingly at meaningful moments; never obstruct the primary task.
- Prefer a few coherent signature details over many unrelated effects.
- Keep playful copy clear, accessible, and appropriate to the user's context.
