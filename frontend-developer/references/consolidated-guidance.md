# Consolidated frontend engineering guidance

Read this for responsive behavior, production resilience, or complex component implementation.

- Preserve semantic HTML, keyboard access, focus visibility, and meaningful labels.
- Design layouts for narrow screens, long text, zoom, and reduced-motion preferences.
- Keep state ownership obvious and handle loading, empty, error, stale, and offline states.
- Avoid fragile fixed dimensions when content or embedded viewports control size.
- Measure before optimizing rendering; prefer fewer dependencies and less client work.
- Verify important flows in a real browser.
