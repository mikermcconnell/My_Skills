# Full Underwriting Quality Checklist

Run this before finalizing a full underwriting.

## 1. Security and market anchor

- [ ] Correct ticker / security identified.
- [ ] Current price has an as-of date.
- [ ] Basic and fully diluted share counts are distinguished.
- [ ] Cash, debt, and enterprise value are reconciled where material.
- [ ] Material warrants, options, convertibles, royalties, streams, or preferred claims are incorporated.
- [ ] Expected future financing is modeled when required for the thesis.

## 2. Evidence discipline

- [ ] Load-bearing facts come from primary or high-quality sources where available.
- [ ] Repeated articles based on one original source are not counted as independent confirmation.
- [ ] Material facts, company claims, derived values, consensus, assumptions, and analyst judgments are visibly distinct.
- [ ] Source dates are appropriate for the claim.
- [ ] Important unresolved conflicts are disclosed.
- [ ] Evidence confidence is stated separately from investment attractiveness.

## 3. Thesis quality

- [ ] The underwriting question is explicit.
- [ ] There are 3-5 falsifiable thesis claims.
- [ ] Major claims use Mechanism -> Metric -> Benchmark -> Falsifier.
- [ ] The variant perception is measurable.
- [ ] The variant perception is not merely "good company", "large TAM", "great management", or "cheap multiple".
- [ ] The analysis states what today's price appears to imply.
- [ ] The underwritten forecast is clearly different from the market-implied path.

## 4. Economic engine

- [ ] The small number of variables that actually create value are identified.
- [ ] Historical evidence is linked to future economics.
- [ ] Sector-specific metrics are used instead of generic metrics where appropriate.
- [ ] Capital intensity and reinvestment are not ignored.
- [ ] Unit economics / project economics / clinical economics are reconciled to equity value.

## 5. Valuation

- [ ] The primary valuation method fits the business.
- [ ] An independent cross-check is used when practical.
- [ ] Valuation assumptions are visible.
- [ ] Multiple expansion is separated from fundamental value creation.
- [ ] The valuation does not double-count the same upside driver.
- [ ] Post-financing value per share is used when material.
- [ ] If valuation methods disagree, the disagreement is explained rather than averaged away.

## 6. Scenarios and downside

- [ ] Bear / Base / Bull are genuinely different economic outcomes.
- [ ] The Bear case contains a credible failure mechanism.
- [ ] The Base case is not a disguised Bull case.
- [ ] The Bull case does not stack every possible upside simultaneously without justification.
- [ ] Financing/dilution differs across cases when appropriate.
- [ ] Value per fully diluted share and return from current price are shown.
- [ ] Permanent capital impairment is discussed separately from volatility.

## 7. Probability and expected value

- [ ] Probabilities are labeled as analyst assumptions unless externally implied.
- [ ] Probabilities total 100% if expected value is calculated.
- [ ] False precision is avoided.
- [ ] Market-implied / break-even probabilities are used when more informative than subjective probabilities.
- [ ] Positive expected value is not allowed to hide unacceptable downside or financing risk.

## 8. Time-to-Resolution Gate

- [ ] Expected holding period is explicit: days, weeks, months, or years.
- [ ] Target realization date is a calendar date.
- [ ] Mandatory re-underwrite date is a calendar date.
- [ ] The reason for each date is explained.
- [ ] Measurable evidence expected by the dates is listed.
- [ ] Delay risk and the valuation cost of time are discussed.
- [ ] The thesis is not allowed to roll forward indefinitely without a fresh underwriting decision.
- [ ] For multi-year investments, the re-underwrite cadence is normally no longer than 12 months unless there is a good reason.

## 9. Red team

- [ ] The strongest credible case against the thesis is presented.
- [ ] The single strongest disconfirming fact is identified.
- [ ] Management incentives / capital allocation are considered.
- [ ] Accounting or metric-quality risks are considered where relevant.
- [ ] Competitive, regulatory, technical, financing, and execution risks are considered where relevant.
- [ ] Takeover / strategic optionality is not required for the Base case unless independently justified.
- [ ] Recent price action is not mistaken for evidence of intrinsic value.

## 10. Catalysts and falsifiers

- [ ] Fundamental catalysts are separated from recognition catalysts and monitoring events.
- [ ] The path for value realization is credible within the stated horizon.
- [ ] There are 3-5 measurable kill criteria.
- [ ] Price decline alone is not used as a kill criterion.
- [ ] The output states what new evidence would change the view.

## 11. Final decision quality

Before issuing the verdict, answer:

1. What exactly is mispriced?
2. What does today's price imply?
3. What must be true for the Base case?
4. What assumption contributes most to upside?
5. What breaks first in the Bear case?
6. Has material financing and dilution been captured?
7. Is the return driven by fundamentals, probability change, or multiple expansion?
8. What is the strongest evidence against the thesis?
9. What evidence would upgrade or kill the thesis?
10. Would the investment still be attractive if takeover optionality were removed?
11. What is the expected holding period?
12. By what calendar date should the thesis be re-underwritten?
13. Is the security actually investable, or merely interesting?

If the important questions cannot be answered, the underwriting is not Decision-ready.

## Allowed final postures

Choose exactly one:

- **INVESTABLE**
- **INVESTABLE, BUT PRICE-SENSITIVE**
- **WATCH / WAIT FOR PROOF**
- **PASS**
- **REJECT**

Then state the next workflow:

- advance toward capital allocation / portfolio-risk review
- targeted follow-up research
- wait for a named catalyst or evidence item
- watchlist / thesis tracker
- stop research
