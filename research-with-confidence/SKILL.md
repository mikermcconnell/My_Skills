# Research With Confidence — strategy-aware

Read ../investment-strategy-lanes/SKILL.md first, then BASELINE_WORKFLOW.md and its task-relevant references. The baseline is the complete inherited RWC workflow. For CAMILLO also read ../camillo-social-arbitrage/SKILL.md.

Begin every investment report with Strategy / Case / Stage / Horizon. Shared facts can support two cases, but Core and Camillo conclusions and handoffs must remain separate. In a single-lane report label the other lane not assessed rather than silently treating it as rejected or doing unsolicited duplicate research.

Core retains its existing mechanism, materiality, expectations, expression and valuation-readiness tests. Camillo uses the same truth standards but can advance a coherent, sourced speculative inference before future adoption, retention or earnings are confirmed. Distinguish verified starting facts, attributed claims, inference and the bet; do not relabel speculation as proven causality. Concentrate on the three decisive checks and plausible alternatives, proportionate to the question.

Use ADVANCE -> FULL UNDERWRITING — CAMILLO MODE in visible handoffs when warranted, preserving existing supported route fields and a strategy-mode annotation rather than inventing API enums. Missing conventional cheapness, a Core buy-level crossing or complete reported financial confirmation is not an automatic Camillo stop. Remaining payoff and instrument approval belong downstream.

Preserve actual case/event lineage and separate confidence in facts, connection, expectations gap and recognition timing. Retain factual independence, owned-instrument defense and all no-trade/no-final-sizing boundaries from the baseline.
